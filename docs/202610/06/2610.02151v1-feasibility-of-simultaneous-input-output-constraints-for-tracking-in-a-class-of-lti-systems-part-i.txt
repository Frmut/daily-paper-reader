# Feasibility of Simultaneous Input-Output Constraints for Tracking in a Class of LTI Systems: Part I 

Junhyeok Yoon 1, Heather Hussain 2, and Anuradha M. Annaswamy 1

Abstract — This paper addresses the problem of simultaneous satisfaction of input and output constraints for LTI systems with multiple inputs with state feedback and integral action using a Control Barrier Function based governor. Necessary and sufficient conditions for the CBF-based governor to have a feasible solution and for the closed-loop solutions to be bounded and forward-invariant are derived. A systematic design procedure for choosing the free parameters of the CBF-governor is also provided. These free parameters are associated with high-order CBFs, bounds on feasible command signals, and control input magnitude. A companion paper provides several numerical examples to illustrate the results of this paper, especially the feasibility (or infeasibility) of the CBF governor when the conditions are satisfied (or not satisfied). 

Index Terms — Constrained control, control barrier functions, feasibility conditions, safety, set invariance. 

I. I NTRODUCTION 

Control Barrier Functions (CBF) have been shown to be powerful tools in dynamic systems and their control for ensuring safety concerns in real-time through the evaluation of a function h(x) and its change in time as the state variable 

x(t) changes (e.g., [1], [2], and a huge literature in control journals and conferences). The safety concerns are often modeled as constraints on key outputs of the dynamic system. Simultaneous satisfaction of output constraints as well as input constraints has been explored in much fewer papers [3]–[12]. The authors of [4], [8] certify forward invariance of an inner subset of the safe set, obtained by bounding the worst-case effect of the input limits, while the authors of [3] obtain such a subset from a backup controller, and the authors of [7] verify the feasibility of multiple CBFs by a sum-of-squares search. All of these conditions, however, are shown to be sufficient. In addition, these methods can be computationally demanding. In [5] the CBF is constructed from a Hamilton–Jacobi reachability value function, which recovers the maximal safe set under input limits but suf-fers from the curse of dimensionality. The authors of [6] introduce an additional CBF that steers the state away from conflicts between the output and input constraints, but it is unclear whether this additional CBF can itself introduce barriers to constraint satisfaction. In [9], [10] it is shown that the CBF constraints admit a feasible input at each state of a set, but that set is not shown to be forward invariant. The paper [12] handles both constraints, but the class of

The authors of [11] consider a general LTI system, include inte-gral action, consider both input and output constraints, and propose a specific augmentation-based control architecture for stability and constraint satisfaction. The feasibility of the latter, however, is not established. Distinct from these papers, input constraints and output constraints have been addressed in a combined manner using a Reference Governor approach which consists of modifying the reference input into the system so as to have the system variables belong to an admissible set where all constraints are met [13]. In this paper, we provide necessary and sufficient condi-tions for when input and output (I-O) constraints have to be satisfied simultaneously and a command signal is to be tracked using a CBF-based Governor for a general class of LTI systems with multiple inputs and integral action, and state feedback. Under these conditions, it is shown that the CBF Governor generates a modified command signal that satisfies I-O constraints with all closed-loop solutions remaining bounded in a given set that is forward invariant. The main contributions of this paper are guarantees that I-O constraints are satisfied, with closed-loop stability, and forward invariance in a given set for a tracking task in a class of LTI systems. We also show how free design parameters of the proposed I-O CBF Governor can be chosen so that the necessary and sufficient conditions can always be satisfied by the underlying closed-loop system with forward invariance of a given set, which corresponds to a relaxation of the input constraints. Finally we delineate as to how an efficient design of the CBF governor can be carried out so as to ensure that this relaxation is minimal. The problem is posed in Section II. The I-O CBF Gov-ernor is described in Section III. Necessary and sufficient conditions for the I-O constraints to be met with closed-loop boundedness are established in Section IV. A design procedure for ensuring that the conditions are always met is described in Section V. A companion paper [14] provides a number of examples to support the theoretical conditions and counter-examples to show when that these conditions can be violated, and how a well-designed I-O CBF Governor can convert these counter-examples into examples. This paper provides necessary and sufficient conditions for I-O constraints to be satisfied simultaneously in a class of closed-loop LTI systems with integral action, for command tracking, using a CBF-based governor that provides a suit-ably modified command. These conditions also imply that for some MIMO plants with state feedback and integral action, it may be impossible to ensure I-O constraint satisfaction. It is also shown in this paper that the SIOCF condition can always be satisfied by expanding the design space where the input constraints are relaxed. A systematic design of the governor parameters is proposed that determines a close to minimal relaxation of the input constraints. Overall, this paper provides an I-O CBF Governor for modifying the command for a class of LTI plants that guarantees that nec-essary and sufficient conditions are always met in ensuring a simultaneous satisfaction of I-O constraints.
